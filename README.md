# Kaiju Brawl! - Description
Play as a very similar looking Kaiju being chased by an army of Mo-... uhm, monsters with wings!
Avoid the cars, avoid the enemies, win big scores. Simple!

Features:
<ul>
<li>A playable kaiju character.</li>
<li>Score and high score counter!</li>
<li>Winged enemies that aim to destroy you. Watch out for their army!</li>
<li>Cars racing off the side, careful; don't get struck.</li>
</ul>
